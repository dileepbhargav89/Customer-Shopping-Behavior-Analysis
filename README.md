# Customer Shopping Behavior Analysis

## 📊 Project Overview
This project analyzes customer shopping behavior to uncover patterns, trends, and insights that help businesses improve sales strategies, customer retention, and decision-making.  
The analysis combines **Python**, **SQL**, and **Power BI** to deliver a complete data analytics workflow—from raw data to interactive dashboards and business recommendations.

---

## 🎯 Business Problem
Understanding how customers shop is critical for:
- Identifying high-value customers
- Improving product recommendations
- Optimizing marketing strategies
- Increasing customer retention

This project answers key questions such as:
- What factors influence customer purchasing behavior?
- Which customer segments generate the most revenue?
- How do shopping patterns vary across demographics?

---

## 🛠️ Tools & Technologies
- **Python**: Data cleaning, exploratory data analysis (EDA), visualization  
- **SQL**: Querying customer behavior data for insights  
- **Power BI**: Interactive dashboards and visual storytelling  
- **Jupyter Notebook**: Analysis documentation  
- **CSV Dataset**: Customer shopping behavior data
